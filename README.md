# 🇺🇸 USA Presidential Election 2020 Analysis

An exploratory data analysis project that examines the **2020 U.S. Presidential Election** using county-level voting data.

## 📌 Project Overview

The project analyzes:

- State and county vote totals
- Vote-counting progress
- Candidate performance
- Party vote distribution
- Counties won by candidates
- Regional voting patterns

## 📊 Dataset

The project uses:

```text
president_county.csv
president_county_candidate.csv
```

The county-level dataset contains:

```text
4,633 records
5 columns
```

No missing values are reported.

## 🗳️ Election Summary

```text
Total Expected Votes : 159,767,210
Total Counted Votes  : 159,608,237
Counting Progress    : 99.90%
```

## 📈 Analysis

The notebook visualizes:

- Top states by total votes
- Top counties by total votes
- National counting progress
- Candidate vote totals
- Party vote distribution
- Counties won by candidate
- Democratic vs. Republican state-level votes

## 🔎 Key Finding

Vote volume varies significantly across states and counties, while candidate performance is strongly aligned with the major political parties.
